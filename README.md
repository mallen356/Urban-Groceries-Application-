This repository contains an automated API test suite developed for the Urban Groceries backend architecture, designed to validate the reliability, performance, and data integrity of its core services. The primary objective of this project is to ensure that all CRUD-operations specifically GET, POST, PUT, and DELETE HTTP requests -function accurately and handle data processing predictably. By establishing a robust regression testing framework, the suite verifies that the API consistently returns the correct HTTP status codes, such as 200 OK and 201 Created, while rigorously asserting that response body payloads match expected schema structures and data requirements.

The automation framework was engineered using JavaScript and the Jest testing library within a Node.js environment, adhering to clean code principles and utilizing asynchronous error-handling practices like try/catch blocks for stable execution. Prior to automation, Postman was utilized for exploratory testing and initial endpoint discovery to establish a baseline for the application's expected behavior. The resulting automated test scripts provide comprehensive coverage across the application's key endpoints, maintaining a 100% pass rate. Ultimately, this project demonstrates a strong proficiency in backend quality assurance, modern API testing methodologies, and the ability to build maintainable, automated validation tools to ensure high-quality software delivery.
